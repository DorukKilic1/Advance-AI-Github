A* Search Explorer

This mini web app teaches how the A* search algorithm finds the shortest path. Build your own maze, watch A* explore nodes step by step, and test your understanding with a small challenge game and quiz.

Key idea: A* chooses the node with the lowest f(n) = g(n) + h(n), where g is the cost so far and h is the estimated distance to the goal.

How A* Works

  1. Start at the green square.
  2. Check neighboring nodes.
  3. For each node, compute g, h, and f.
  4. Always expand the node with the lowest f.
  5. Stop when the goal is reached and reconstruct the best path.
